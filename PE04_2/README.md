# Input
The user is only able to make one input to this application. Each ProfileCard has a showThumbnail state. The user can toggle the showThumbnail state value by clicking on the respective card.

# Process
The size of the ProfileCard is modified based on its showThumbnail value. If showThumbnail is true, the card displays at a fraction of its full size.

# Output
The program displays ProfileCards for a variety of book characters.
